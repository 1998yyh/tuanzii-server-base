# 筛选日和距今涨幅

> 本文记录最初的腾讯实现。随后按用户要求将循势涨幅统一为东方财富，当前实现与验证边界以 `2026-10-27-unify-market-source-impl.md` 为准；下面保留当时的开发记录。

日期：2026-10-27。前后端分支均为 `feature/signal-price-returns`。

## 需求和价格口径

循势筛选结果增加“当日涨幅”和“距今涨幅”。“当日”指所选筛选日期，不能默认用今天的涨幅代替历史日期。

- 历史筛选日的当日涨幅：`(该日前复权收盘价 / 前一交易日前复权收盘价 - 1) × 100%`。
- 距今涨幅：`(最新报价 / 筛选日前复权收盘价 - 1) × 100%`。前复权基准使用源站本次返回的序列，当前最新报价使用同一响应内的报价，不拼接其他来源。
- 筛选日就是今天时，当日涨幅读取同一响应中的当日报价涨跌幅；盘中无最终收盘基准，距今涨幅返回 null，原因“基准日未收盘”。上海时间到 15:00 且源站报价也已到当天 15:00 后才允许建立当日收盘基准。
- 所选日期缺失时不借用附近交易日；缺少前一交易日、无效价格、无效或过早/未来报价时间均明确缺失。非交易日或停牌期间保留最后报价的实际时间，不伪造今天的报价。

历史百分比按源站前复权价格计算并保留两位小数，受其历史价格精度影响，可能与行情软件展示的官方日涨幅有小幅差异。已验证可获取华电辽能、富奥股份在 2026-09-10 的基准与前一交易日价格及最新报价。对这两个股票执行新服务只读查询，均返回当日与距今百分比以及真实报价时间；没有写数据库或操作观察池。

## 数据源与接口

采用腾讯财经 `https://web.ifzq.gtimg.cn/appstock/app/fqkline/get`，参数 `symbol,day,start,,640,qfq`。`start` 为筛选日期往前 45 个日历日，读取 `qfqday` 和 `qt[symbol]`。一次源站请求拿到历史和最新报价，不回退到未复权 `day`。东方财富日线接口本次连续只读验证出现连接中断，因此未将其作为这个功能的依赖，已有板块接口仍保持东方财富来源。

新增公开只读接口：

```text
GET /api/stock-signals/performance?date=2026-09-10&codes=600396,000030
```

日期需是真实日历日期且不晚于上海今天，代码沿用沪深主板校验，单次最多 50 只。返回 `items`，每项包含：

| 字段 | 含义 |
| --- | --- |
| code / date | 股票与本次筛选日期 |
| dayPercent / sincePercent | 百分比数值；缺失为 null，真实零为 0 |
| dayReason / sinceReason | 对应缺失原因；有数值时为 null |
| quoteAsOf | 源站实际报价时间，ISO UTC；未取到有效时间为 null |
| source / adjustment | 固定 tencent / qfq |
| fetchedAt | 本次取数时间，不替代实际报价时间 |

服务全局最多四个源站请求，同日期同股并发合并，按日期和代码缓存。有效/部分有效结果缓存 30 秒，全缺失缓存 5 秒，缓存最多 1000 项。固定出站地址也经过 SSRF 校验，禁止重定向，单次超时 8 秒。一只股票失败不影响其他股票。

前端新 composable 分批十只、两个并发任务加载，每轮结束后 30 秒再刷新，页面不可见时跳过该轮刷新。日期变化、手动重试和卸载取消旧请求与定时器。展示组件保留原勾选、入池和板块功能，上涨用暖红、下跌用深蓝、零值用灰色，无绿色配色。

## 验证与发布

`pnpm lint`、`pnpm typecheck`、`pnpm build` 通过。新增专项测试 29 项通过，全量 Jest 69 个套件、745 项全部通过。前端单元测试、lint、构建和隔离浏览器测试通过，覆盖两种涨幅、正负和零值、日期切换、失败重试、待收盘、自动刷新及卸载取消，桌面和手机端截图已检查。

不涉及数据库、依赖或配置迁移，不改变已有信号计算及观察池状态。先发布后端新增接口，再发布前端；旧后端 404 时前端保留股票结果，涨幅显示“行情暂不可用”。目前仅提交功能分支，尚未合并或部署。

限制：数据依赖第三方公开行情，日线返回最多 640 条；若窗口中没有目标日/前一交易日或缺少复权数据，明确返回缺失。没有把该功能解释成用户实际交易收益。回退时先恢复旧前端，再移除新接口、服务和模块注册；无需回滚数据库数据。
